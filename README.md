## 🎯 Project Overview

This is a university club project created for the graduation exhibition.

As the team leader, I was responsible for communication and the overall front-end development.

The system includes robots that classify and compress trash, and collect compressed trash cans.

We manage collection data, status monitoring, and storage using Firebase.

---

## 🚀 Project Start (2024/05/01)

### 📦 Required Tools
1. [Node.js](https://nodejs.org/)
2. VS Code  
   - Live Server Extension  
   - HTML / CSS

### ☁️ Deploy to Firebase
1. Enter Windows PowerShell administrator mode
2. `firebase init hosting`
3. Choose: `Use an existing project`
4. Set: `public directory = .`
5. Set SPA mode: `Yes`
6. `firebase deploy`
7. Try your own domain 😎

### ☁️ When updating content
1. Enter Windows PowerShell administrator mode
2. `firebase init hosting`
3. Choose: `Use an existing project`
4. Set: `public directory = .`
5. `firebase deploy`
6. Go into my domain and see the changes 😎


### 📊 Firebase Plan Info

We are currently using the **Spark (Free) Plan**, and the limits are:

| Service           | Usage Limit                                   | Notes                                      |
|-------------------|-----------------------------------------------|--------------------------------------------|
| **Hosting**        | 10 GB storage / 10 GB downloads per month     | Used for HTML, CSS, JS, images             |
| **Cloud Firestore**| 1 GB storage / 20,000 writes / 50,000 reads per day | Used for live data, logs, and statistics   |
| **Independence**   | ✅                                              | Hosting and Firestore **do not share limits** |

> ✔️ We monitor both independently to prevent service disruption.
