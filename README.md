# MCA_AI-Trash-Classification-System_UI

## This Project is..

As a university club project, I started to create works to be exhibited in the graduation exhibition.

As the team leader of the project, I was in charge of communication and front-end overall among various parts.

Our project consists of robots that add classification and compression functions to the trash can and collect compressed trash cans.

We plan to manage collection information, data storage, reading, and status using Firebase.
